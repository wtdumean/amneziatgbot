# AmneziaVPN Telegram Bot

Telegram-бот для управления VPN-профилями [AmneziaVPN](https://amnezia.org) через [amnezia-api](https://github.com/kyoresuas/amnezia-api). Поддерживает модульное расширение, интеграцию с веб-сервисом и административный контроль.

## Возможности

### Для пользователей
- 🔐 **Мультипрофили** — несколько независимых VPN-профилей.
- 📥 **Получение конфига** — строка `vpn://…` и `.vpn`-файл для импорта в AmneziaVPN.
- 👤 **Статус профиля** — онлайн/офлайн, трафик, время последнего подключения.
- 🗑 **Удаление профиля** с синхронизацией в Amnezia API.
- 🖥 **Статус сервера** — регион, протокол, количество клиентов.
- 🔑 **Секретный ключ** для восстановления VPN-профиля.
- 🌐 **Веб-интерфейс Mini App** для управления через Telegram.

### Для администраторов
- 👥 Список пользователей с пагинацией (кликабельные ID → профиль в Telegram).
- 🃏 Детальная информация о пользователе: профили, трафик, IP, статус.
- 🚫 Бан/разбан пользователей.
- 🗑 Массовое удаление и управление профилями через админ-панель.
- 📊 Cтатистика: трафик, топ пользователей, онлайн.
- 🔍 Поиск пользователей по Telegram ID или имени профиля.
- 📢 Массовая рассылка сообщений.
- 📋 Экспорт пользователей в CSV.
- 🔒 Режим "только админы" (`BOT_MODE=admin`).

└──────────────────┘     └─────────────────────┘     └────────────────────┘

## Установка и конфигурация

### Шаг 1: Установка зависимостей
```bash
mkdir -p /root/bot && cd /root/bot
git clone https://github.com/wtdumean/amneziatgbot.git
cd amneziatgbot

python3 -m venv env
source env/bin/activate
pip install -r requirements.txt
```

### Шаг 2: Настройка `.env`
Создайте файл `.env` на основе примера `.env.example`:
```env
BOT_TOKEN=ваш_токен_бота
ADMIN_IDS=[123456789,987654321]
BOT_MODE=all
AMNEZIA_API_URL=http://localhost:4001
AMNEZIA_API_KEY=секретный_ключ
DB_PATH=./data/bot_data.db
```

### Шаг 3: Запуск сервиса
```bash
chmod +x start.sh
./start.sh
```

## Структура файлов

```
/root/bot/
├── bot.py              # Основной файл: хендлеры, middleware
├── admin_handlers.py   # Логика для админов
├── shared.py           # Вспомогательные функции, клавиатуры
├── config.py           # Конфигурация проекта (Pydantic)
├── database.py         # SQLite клиент с шифрованием
├── security.py         # Модуль безопасности
├── miniapp.py          # Telegram Mini App (Flask)
├── web_service.py      # Веб-сервис конфигов (Flask)
├── requirements.txt
├── start.sh            # Скрипт запуска
└── .env                # Переменные окружения
```

## Зависимости

Основные библиотеки:
- **aiogram**: управление ботом Telegram.
- **Flask**: разработка API и веб-сервисов.
- **Pydantic**: управление и проверка настроек.

Полный список зависимостей в `requirements.txt`.

## Частые проблемы

1. **Бот не отвечает**
   - Проверьте токен и работа ли API `amnezia-api`.

2. **Ошибки базы данных**
   - Перезапустите процессы, блокирующие SQLite.
